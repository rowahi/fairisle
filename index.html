🗂 Meine Muster

Muster antippen zum Öffnen. Alles wird automatisch gespeichert.

Ein Projekt reiht mehrere Rapporte und Farbstreifen untereinander – z. B. für einen Pullover oder eine Mütze.

Kachel antippen = neues Muster. „📋 Einsetzen“ = Motiv in den aktuellen Rapport stempeln.

Text oder Code einfügen

Ein Muster-Code (beginnt mit FI1:) oder ein Buchstaben-Raster: eine Zeile pro Reihe, oberste Reihe zuerst.

⚠ Wichtige Hinweise

  • Alle Muster, Projekte und Garne werden nur lokal in diesem Browser auf diesem Gerät gespeichert – nicht im Internet. Ein anderer Browser oder ein anderes Gerät sieht sie nicht.
  • Browserdaten, Cache bzw. „Website-Daten“ nicht löschen und nicht im privaten Fenster arbeiten – sonst ist alles verloren.
  • Regelmässig sichern: Gesamtsicherung herunterladen (alles in einer Datei). Damit lassen sich die Daten auch auf einen anderen PC übertragen.
